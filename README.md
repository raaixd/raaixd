## Projects

### [WeMentors AI](https://github.com/raaixd/wementorschatbot)
Conversational RAG assistant running in production on the WeMentors site. Rewrites follow-up questions, retrieves with a hybrid lexical and semantic pipeline, and validates every answer against a verified knowledge base, falling back to "I don't know" instead of guessing. Retrieval changes are benchmarked before they ship.

`Python` `FastAPI` `RAG` `Gemini` `Groq` `SQLite` `pytest` `Vercel`
<br />
<sub>Live · [Demo](https://wementors.vercel.app)</sub>

<br />

### [Aletheia](https://github.com/raaixd/aletheia)
AI-powered incident investigation. Builds an evidence graph from logs, traces, metrics and deploys, proposes competing root-cause hypotheses, and has an adversarial verifier challenge each one before a diagnosis is made. Benchmarked on 20 reproducible incidents across 15 failure categories against single-LLM and two-agent baselines.

`Python` `LangGraph` `FastAPI` `PostgreSQL` `OpenTelemetry` `Next.js` `Docker`
<br />
<sub>In development · [Live](https://aletheia-khaki-tau.vercel.app) · [API docs](https://aletheia-backend-ten.vercel.app/docs)</sub>

<br />

### [VERIDEX](https://github.com/raaixd/datapilot-ai)
AI data analyst for CSV, Excel and multi-table ZIP uploads. Turns plain-English questions into validated, read-only SQL with metrics, charts and exportable reports. SQL safety is enforced in code, and ambiguous questions get a clarifying question instead of a guess.

`Python` `SQL` `DuckDB` `Pandas` `FastAPI` `Streamlit` `AWS`
<br />
<sub>Stable · 375 tests passing</sub>
